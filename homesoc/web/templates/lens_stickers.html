Pair a phone Devices Dashboard

Each code is an opaque random token — it carries no MAC address, IP, hostname or device name, so a photograph of a sticker tells a visitor nothing about the network. Reprinting is safe: the same device keeps the same code, and stickers already stuck to things keep working. The caption is only ever the nickname you chose, or the kind of device (“camera”) when it has none — never its hostname, IP address or MAC address.
